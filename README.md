# Applied AI Engineering

A 12-week, build-first study guide for AI engineering: building software with LLMs at its core. It covers calls and structured output, evals, tool use and workflows, retrieval, agents, MCP, observability and cost, security, deployment, and forward-deployed engineering. One running project (a support-desk assistant) grows each week. About 7.5 hours a week, Oct 12, 2026 – Jan 3, 2027.

The page is a single landing page: a system diagram, an interactive concept map showing how the 24 concepts connect, week-by-week steps with self-checks, hiring signals and resources.

**Live site:** https://wongrichardh.github.io/ai-engineering-fundamentals/

## Files

- `study-plan.html`: the guide (source, written as an artifact fragment).
- `index.html`: standalone version served by GitHub Pages, generated from `study-plan.html`.
- `build.sh`: regenerates `index.html`. Run `sh build.sh` after editing `study-plan.html`.
