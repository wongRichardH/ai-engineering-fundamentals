# Applied AI Engineering (12 Weeks)

A 12-week, build-first study plan for AI engineering: building software with LLMs at its core. Calls and structured output, evals, tool use and workflows, retrieval, agents, MCP, observability and cost, security, deployment, and forward-deployed engineering. One running project (a support-desk assistant) grows each week. About 7.5 hours a week, Oct 12, 2026 – Jan 3, 2027.

v3 replaces the earlier 8-week ML foundations plan (training, transformers, inference), which is in the git history.

**Live calendar:** https://wongrichardh.github.io/ai-engineering-fundamentals-8-weeks/

## Files

- `study-plan.html`: the plan and scrollable week-by-week calendar (source).
- `index.html`: standalone version served by GitHub Pages, generated from `study-plan.html`.
- `build.sh`: regenerates `index.html`. Run `sh build.sh` after editing `study-plan.html`.
- `daily/`: nightly summaries shown in the page's Today panel (see `daily/README.md`).
