Applied AI Engineering

Build software with an LLM at its core: call models, validate what comes back, give them tools and data, measure them with evals, and ship them to a customer. You build one system, a support-desk assistant for a small online store, and add a layer every week.

Oct 12, 2026 – Jan 3, 2027 12 weeks in 4 blocks ~7.5 h a week 24 concepts

Overview

What you build

The model is one component, not the product. An AI engineer builds the software around a call that can return something different every time: what goes in (context and tools), what is allowed out (schemas and validation), what it can touch (permissions), and how you know it works (evals and traces). None of it requires training a model.

  1. Weeks 1–3 · Call, validate, measureHow do I get reliable output from an unreliable call?

    API calls, typed output with validation and retries, then evals in CI.

  2. Weeks 4–6 · Tools, retrieval, agentsHow does the model act on real data?

    Tool use and workflow patterns, hybrid retrieval, then an agent loop by hand and with an SDK.

  3. Weeks 7–9 · ProductionHow do I run it safely and cheaply?

    MCP servers and integrations, tracing and cost, then prompt-injection defenses.

  4. Weeks 10–12 · Deploy and deliverHow do I ship it to a customer and show the work?

    Eval-gated deploys, a forward-deployed customer exercise, then portfolio and interview practice.

The ladder for this guide is single call → workflow → agent. Add autonomy only when your evals show the simpler version fails.

Before Week 1

  • Python 3.11+ with uv or a virtual env, Git and a GitHub repo for the project.
  • Comfort with HTTP APIs, JSON and async Python. FastAPI's tutorial covers enough.
  • API keys for Anthropic and OpenAI, each with a small monthly spending limit.
  • Docker and Postgres (local, or a free Supabase or Neon project).
  • An AI coding tool (Claude Code, Cursor or Codex), used every week.

Left out on purpose

  • Training, fine-tuning and ML math.
  • Frontend beyond a minimal page. About a third of postings mention it; add it if your targets do.
  • Kubernetes and deep MLOps. W10 deploys to one managed platform.
  • Holidays: Thanksgiving falls in W7, Christmas in W11, New Year in W12. Use Saturdays to catch up.
